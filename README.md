# 🔊 Windows Sound & Alert Generator

> **A sleek, modern CustomTkinter desktop utility to trigger native Windows warning alerts and system chimes with custom text.**

---

## ✨ Features

- **Modern Glassmorphism Aesthetic:** Translucent UI (`85%` window transparency) built with `CustomTkinter`.
- **Custom Alert Messages:** Easily test custom notification titles and sound triggers.
- **Native OS Sound Integration:** Triggers the built-in Windows warning sound effect via `tkinter.messagebox`.

---

## 🛠️️ Tech Stack

- **Language:** Python 3.10+
- **GUI Framework:** [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter)
- **Native OS Modules:** `tkinter.messagebox`
